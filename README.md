# Olá, sou o Danilo 👋

Estudante de **Ciência da Computação na UNIFEI** (Itajubá, MG), com previsão de formatura em dez/2027. Trabalho com dados e Machine Learning aplicados a problemas reais, principalmente **séries temporais e detecção de anomalias**.

- 🔬 **Pesquisador de Machine Learning (bolsista) em P&D com a Petrobras / FAPEPE**, com séries temporais industriais de pressão:
  - detecção automática de eventos no sinal bruto com filtro de Kalman + máquina de estados;
  - classificação com CNN 1D (~90% de acurácia), Random Forest, SVM, LSTM e BiLSTM, com aumento de dados via LSTM-VAE;
  - detecção de anomalias em tempo real com Isolation Forest (AUC ~0,93), com sugestão de encerramento antecipado do teste;
  - benchmark de 16+ modelos com Optuna, várias seeds e validação por grupo: Isolation Forest, One-Class SVM, LOF, Elliptic Envelope, PCA / Kernel PCA, GMM, KDE, Autoencoder, VAE, CNN 1D, LSTM, GRU e CNNs sobre transformada wavelet e FFT.

- 📊 **Estagiário em Dados e BI na UNIFEI:** extração com SQL, limpeza e consolidação de bases com Python e dashboards em Power BI.
